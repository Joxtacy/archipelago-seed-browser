# Archipelago Seed Browser

A launcher add-on for [Archipelago](https://archipelago.gg) that lists the
multiworld seed zips in your local output folder and exposes per-seed actions
(host, view spoiler, reveal in file manager, delete).

Ships as a single `.apworld` you drop into your Archipelago `custom_worlds/`
directory.

Working spec lives in [`PLAN.md`](PLAN.md); reference notes about the AP API
surface live in [`NOTES.md`](NOTES.md); post-v1 ideas land in
[`IDEAS.md`](IDEAS.md).

Status: pre-release. v1.0.0 not yet tagged.
